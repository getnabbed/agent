{{- $ns := .Release.Namespace -}}
{{ .Values.replicas }} Nabbed agent(s) deployed as StatefulSet {{ $ns }}/{{ $fullname }}.

Each agent pairs on first start. Print the latest pairing link and code
each agent logged (agents already paired print nothing):

  for i in $(seq 0 {{ sub (int .Values.replicas) 1 }}); do
    kubectl -n {{ $ns }} logs {{ $fullname }}-$i --tail=200 \
      | jq -rR --arg pod {{ $fullname }}-$i 'fromjson? | select(.user_code) | "\($pod): \(.verification_uri)  code \(.user_code)"' \
      | tail -1
  done

Open each link, check the code matches, and approve. A code expires after
a few minutes; the agent then exits and Kubernetes restarts it with a new one.

Check an agent:

  kubectl -n {{ $ns }} exec {{ $fullname }}-0 -- agent status

If an agent is revoked it exits with code 3 and crash-loops. To pair it
again with a new identity, replace its data claim:

  kubectl -n {{ $ns }} delete pvc data-{{ $fullname }}-0 --wait=false
  kubectl -n {{ $ns }} delete pod {{ $fullname }}-0
